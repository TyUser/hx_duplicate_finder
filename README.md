# hx_duplicate_finder

Утилита на Rust для поиска и удаления дубликатов файлов в указанной директории. Использует алгоритм хёширования SHA-256 для точного сравнения содержимого файлов и поддерживает автоматическое удаление дубликатов в зависимости от настроек.

## Возможности
- **Поиск дубликатов:** Сканирование директорий и обнаружение файлов с одинаковым содержимым. Обрабатываются файлы размером от 1 КБ до 1 ГБ (файлы без расширений игнорируются).
- **Хёширование:** Использование SHA-256 для точного сравнения файлов.
- **Исключения:** Поддержка списков исключений для директорий, файлов и расширений.
- **Удаление дубликатов:** Автоматическое перемещение дубликатов в корзину.
- **Логирование:** Запись всех операций в лог-файл `process.log`.

## Сборка из исходников
- Установите [Rust](https://www.rust-lang.org/).
- Клонируйте репозиторий и перейдите в директорию проекта.
- Соберите проект:
 ```bash
   cargo build --release
   ```
- Исполняемый файл `hx_duplicate_finder.exe` появится в папке `hx_duplicate_finder\target\release`.

## Использование
1. Поместите `hx_duplicate_finder.exe` в директорию, которую необходимо просканировать, и запустите его.
2. Программа проанализирует текущую папку и все вложенные директории.
3. При первом запуске программа создаст папку с настройками: `C:\Users\<Имя_пользователя>\Documents\hx_settings`:
- **folders.txt** — список исключаемых директорий.
- **files.txt** — список исключаемых файлов.
- **extensions.txt** — список разрешённых расширений.
- **delete.txt** — режим работы. По умолчанию `no` (только просмотр). Для активации удаления измените значение на `yes`.

## Важные примечания
- **Платформа:** Windows 10/11.
- **Безопасность:** По умолчанию программа работает в режиме "только просмотр". Удаление включается только через `delete.txt`. При некорректных настройках параметры автоматически исправляются.
- **Восстановление:** Все удалённые файлы перемещаются в корзину, что позволяет восстановить их при ошибке.
- **Производительность:** Скорость сканирования зависит от скорости работы диска и объёма данных.
